# click-and-collect

Application de retrait de commandes en click & collect pour commerçants et clients de proximité.

## Structure du dépôt

- `backend/` — API NestJS + PostgreSQL (auth, boutiques, produits, créneaux, commandes, paiement simulé, WebSocket temps réel)
- `mobile/` — application cliente/commerçante React Native (Expo)
- `admin-web/` — back-office Next.js
